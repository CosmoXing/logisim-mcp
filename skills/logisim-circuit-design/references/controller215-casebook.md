# 实验4 控制器模块（CU）2.15 实战复盘

> 交付：`待修/全套210/实验4 控制器模块.circ`（17 个电路：实验2/3 复用 7 个 + 新增 10 个）。
> 工具：`scripts/v215/board215.py`（扩展）、`calib_lab4.py`、`gen_ctrl_lab4.py`、`verify_ctrl_lab4.py`。
> 验证：9 个电路共 112 行时序/组合向量，全过；`ERRCOUNT 0`。

## 1. 电路结构

| 电路 | 规格 | 验证 |
|---|---|---|
| Regs | R0~R3（8 位），写使能 = 2-4 译码(C-Reg) AND R/W，CLK 上升沿写入；A/B 各一个 4:1 MUX（SA/SB） | 16 行 |
| PC | 8 位寄存器 + 8 个全加器行波进位 + 2:1 MUX（常数 1 / Offset），TC_en、RST、P_addr | 14 行 + 进位链 0xFF 用例 |
| IR | 16 位寄存器，TF 使能，I_out | 8 行 |
| ID | X/Y/Z → R/W、S-B/I、RM、WM、JP、JZ、JC（按 PDF 真值表） | 8 行（穷举） |
| CLK 模块 | 2 位同步计数器（两个 1 位 Register）+ 门级 2-4 译码 → T0~T3 | 12 行 |
| S-I/B | B[8] 与 4 位立即数（零扩展）二选一 | 5 行 |
| Flag | 4 位寄存器（Z/C/S/O），带 en/RST | 10 行 |
| CU 控制器 | IR + ID + PC；TF=T0 取指、TC=T3 改 PC；跳转选择 = JP + JZ·Z + JC·C | 20 行 |
| 系统连接 | CLK/ROM/CU/Regs/S-I/B/ALU/RAM/Flag/MUX，ROM 为 PDF 样例 8 字 | 19 行 |

## 2. 指令字段与真值表

16 位指令：`[15:13] = XYZ`（X 为最高位）、`[12:8] = S-op`、`[7:0] = S-Regs`。

| XYZ | R/W | S-B/I | RM | WM | JP | JZ | JC |
|---|---|---|---|---|---|---|---|
| 000 | 1 | 0 | 0 | 0 | 0 | 0 | 0 |
| 001 | 1 | 1 | 0 | 0 | 0 | 0 | 0 |
| 010 | 0 | 0 | 0 | 1 | 0 | 0 | 0 |
| 011 | 1 | 0 | 1 | 0 | 0 | 0 | 0 |
| 100 | 0 | 1 | 0 | 0 | 1 | 0 | 0 |
| 101 | 0 | 1 | 0 | 0 | 0 | 1 | 0 |
| 110 | 0 | 1 | 0 | 0 | 0 | 0 | 1 |
| 111 | 0 | 0 | 0 | 0 | 0 | 0 | 0 |

注意：**S-B/I 在 100/101/110 也为 1**，容易只按 001 一项实现。

S-Regs 拆分（系统连接）：bit2-3 = C-Reg、bit4-5 = SA、bit6-7 = SB；bit0-3 兼作 4 位立即数。
S-op 映射：bit0=Cin、bit1=S0、bit2=S1、bit3=S2、bit4=S3；`10000` = 加法。

## 3. 时序（系统连接实测）

一个指令周期 = 4 个 T：

| 拍 | 动作 | 触发边沿 |
|---|---|---|
| T0 | IR 锁存 ROM 数据（取指） | T0 上升沿 |
| T1 | ID 译码（组合） | — |
| T2 | ALU 运算（组合） | — |
| T3 | PC 改值（+1 或 +Offset）、Regs 写回、RAM 写 | T3 上升沿 |

计数器在 `CLK` 上升沿加 1，T0~T3 由计数值门级译码。实测顺序：
复位释放后第一拍为 T1（计数器 0→1），随后 T2、T3、T0 循环；
PC 在 T3 上升沿加 1；IR 在 T0 上升沿锁存。
`PC = 0x31` 的样例来自 ROM 中 `0x8030`（JP，偏移 0x30）在 PC=1 时执行。

## 4. 这次踩到的坑（2.15.0.2 实测）

### K20 Register 端口不是 2.7.1 那套

```
D(-30,0) en(-30,+10) clk(-20,+20) clr(-10,+20)
preset(-10,-20) cs(-30,-10) Q(0,0)；体 (-30,-20)..(0,+20)
```

- `cs` 是片选：默认 `selection=low` 时 **cs=0 才输出**（与 2.7.1 一致）。
- `en` 只有等于 FALSE 才禁止加载；悬空/1 都加载。
- `clr`/`preset` 高有效；不用的脚接 0。
- **用 CLK 做使能门控会边沿竞争**：`en = 译码 & R/W & CLK` 在上升沿可能先看到旧 en=0，
  寄存器不写。正确做法：`en = 译码 & R/W`，`clk = CLK`（或 T3）。

### K21 2.15 内置 Adder 不可用

`lib=3 name=Adder` 的 5 个端口里，`Cout` 被声明成输入脚
（`(x-20,-20)=Cin`、`(x-20,+20)=Cout`），全接 0 后 `S` 仍为 `U`。
PC 的加法改用 **8 个「全加器」子电路行波进位**，一次通过（含 0xFF+1 进位测试）。

### K22 Counter 是减计数器

`lib=4 name=Counter`，`width=2`、`trigger=rising`，`max/goal` 省略或写 `max=3,goal=wrap`，
复位后序列都是 `0 → 3 → 2 → 1 → 0`（向下计数）。CLK 模块改用两个 1 位 Register
搭同步计数器：`D0=~Q0`、`D1=Q1 xor Q0`，再门级译码 T0~T3。

### K23 RAM 的 cs/oe 极性

`lib=4 name=RAM`（`bus=separate`）：

```
A(-140,0) D(-140,+20) Q(0,0)
str(-110,+40) cs(-90,+40) clk(-70,+40) oe(-50,+40) clr(-30,+40)
```

- **cs 低有效、oe 高有效**：`cs=0, oe=1` 才能读出 Q；`oe=0` 时 Q=`U`。
  两个都接 0 会得到「写可能成功、读永远 U」的假象。
- `str=1` + `clk` 上升沿写入。

### K24 ROM 的 cs

`lib=4 name=ROM`：`A(-140,0) Q(0,0) cs(-90,+40)`，`cs=0` 输出有效；
contents 写法 `addr/data: 3 16\n4001 8030 ...`（元素文本，不是属性）。

### K25 多分支 Splitter

`fanout` 是分支数、`incoming` 是总位数；`bit{i}` 的值是第 i 位所属分支（0 = 最右）。
端口位置只与分支数有关：`b_i = (x + off - 10i, y ± 20)`，`off=((fanout+1)//2-1)*10`。
例：16→2（8/8）branch0 在 `(x, y+20)`、branch1 在 `(x-10, y+20)`。

### K26 子电路外观：`pin` 必须写真实 Pin 坐标

`<circ-port pin="120,100"/>` 里的坐标必须等于子电路内 Pin 的 `loc`。
写错不会报错，Logisim 会把该端口按默认外观压到符号顶边（10px 密排），
表现为「父电路连线对不上、内部全 U」。
改完必须用 `ita_probe.ends` 在父电路里核对实例端口坐标。

### K27 字段位序

`[15:13]` 按 X(bit15)、Y(bit14)、Z(bit13) 读，才与 PDF 真值表的 3 位组合一致。
按 bit13→X 接线会把 001 与 100 对调（JP 误触发）。

### K29 隧道/引脚的可视间距（布局美观）

Logisim 的隧道标签盒从 loc 向 facing 方向伸出约 `8*字数+8` × 26 px，紧贴端口会压住引脚本体。

- 引脚引出：`Board.lead()` 默认 80px，再放隧道；输出引脚同理。
- 同侧多脚扇出：`fan_stub` 横向 `20+30i`、纵向交替 `±25`；`fan_bits` 30px 步进。
- 寄存器辅助脚：`wire_reg()` —— D 直出 70px；EN 西 40 再上 40；CLK 南 40；CLR 南 40 再东 80；`cs/preset` 悬空（默认使能，不画隧道）。
- MUX 的 out/sel 用 40px 引出，否则会压住 MUX 符号。
- 子电路外观的 `circ-port pin` 必须是内部 Pin 的真实 loc；写错会被静默压到符号顶边。
- 用 `ovl2.py`（按 facing 方向建模隧道盒）检查可视重叠；本轮把实验4 从 80 处降到 33 处（Regs/PC/ID 为 0），实验3 也同步重排。

### K28 手工 `--set` 不可靠

2.15 探针的 `--set` 单次求值经常读到全 0（引脚值没落到网上）；
时序/组合验证一律走 `--vector`，必要时加 `--trace` 逐行打印所有引脚。
