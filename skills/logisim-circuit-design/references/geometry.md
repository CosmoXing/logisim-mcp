# 几何与电气规则（实测，非推测）

> **先确认版本。** 本文数据默认 **logisim-evolution 5.0**（`<project source="5.0.0">`）。
> 3.9 的门 `size` 是 40，输入口在 `loc.x-20`；5.0 是 50，输入口在 `loc.x-50`。
> 差 30px 的症状是「每修好一处、另一处又坏」，会被误判成布线算法有问题。

坐标系：x 向右、y 向下，网格 10px。所有 `loc` 都是元件锚点，但**不同元件的锚点含义不同**，这是最容易错的地方。

## 0. 3.9 → 5.0 差异速查

| 项 | 3.9 | 5.0 |
|---|---|---|
| 引脚写法 | `<a name="output" val="true"/>` | `<a name="type" val="input"/>` / `val="output"` |
| 门默认 `size` | 40 | 50 |
| AND/OR 输入口 | `loc.x-20` | **`loc.x-50`** |
| NAND/NOR 输入口 | `loc.x-20` | **`loc.x-60`**（反相圈 +10） |
| XOR 输入口 | `loc.x-20` | **`loc.x-60`**（曲线护盾 +10） |
| XNOR 输入口 | `loc.x-20` | **`loc.x-70`** |
| NOT 输入口 | `loc.x-20` | **`loc.x-30`**（特例，宽度 30） |
| 子电路端口 | `loc.x-30` 起、10px 间距 | 按 facing 分边，锚点落在东边第一个口 |

判断方法：`head -3 xxx.circ | grep source`，或看 Logisim 窗口标题。

## 1. 引脚 Pin

```
loc = 连线接点
input  : facing="east"，导线从 loc 向右引出，标签画在 loc 左侧
output : facing="west"，导线从 loc 向左引出，标签画在 loc 右侧
```

- 输入引脚的标签在**左边**。若引脚放在 `x=0`，标签会被画布左边界裁掉，看起来「没有标签」。左侧至少留 100px。
- 引脚本身不占宽高，可以直接把 `loc` 当走线端点。
- 5.0 的引脚类型由 `type` 属性决定；写成 `in` / `out` 会被忽略（引脚变成无类型的"普通引脚"，网络全 `U`）。

## 1.1 其他单端口器件

| 器件 | 端口 | 说明 |
|---|---|---|
| `Pin` | `(0,0)` | 类型由 `type` 属性决定 |
| `Clock` | `(0,0)` | 输出口就在 loc 上，向右接线 |
| `LED` | `(0,0)` | 无方向，按网络取值点亮 |
| `Hex Digit Display` | `(0,0)` | 数据口 4 位；小数点 `(20,0)` |
| `Constant` | `(0,0)` | 值用 `value="0x1"` 这类写法 |
| `Tunnel` | `(0,0)` | 同层相同 `label` 视为同一网络（作业通常禁用） |

## 2. 逻辑门

```
loc = 输出口（所有门都一样）
输入口 x = -(size + bonus + 反相圈*10)
```

| 门 | 宽度 | 2 输入口 | 1 输入 | n 输入（n≥3） |
|---|---|---|---|---|
| AND | 50 | `(-50, ∓20)` | `(-50, 0)` | `y = -10(n-1) + 20i` |
| OR | 50 | `(-50, ∓20)` | 同上 | 同上 |
| NAND | 60 | `(-60, ∓20)` | | |
| NOR | 60 | `(-60, ∓20)` | | |
| XOR | 60 | `(-60, ∓20)` | | |
| XNOR | 70 | `(-70, ∓20)` | | |
| **NOT** | **30** | — | **`(-30, 0)`** | — |

- 包围盒：`(-width, -max(10n,50)/2) .. (0, +max(10n,50)/2)`。
- `size` 属性是外观枚举（0/1/2…），不是像素值；改它会改宽度，进而改输入口坐标。
- **`WireRepair` 吸附**：线端落在门包围盒内会被吸到最近的输入口，所以 AND 接 `-20`（盒内）也能通、接 `-60`（盒外）一定悬空。
  能通不代表对——**布线仍要精确落在端口上**，否则换个门型就断。

## 3. 触发器（D / T，classic 外观）

```
D   : (-40, +20)      T 触发器时同一位置是 T
CLK : (-40,   0)
Q   : (  0,   0)
~Q  : (  0, +20)
R   : (-10, +30)      异步清零，高有效
S   : (-30, +30)      异步置位，高有效
```

- 包围盒 `(-40,-10) .. (0,+30)`。
- ⚠️ `Q(0,0)` 与 `~Q(0,20)` 只隔 20px：**任何从右侧竖直穿过触发器的导线都会把两者短接**，输出 `E`。
  布线器必须把所有元件端口列为禁入点，不只是元件体。
- ⚠️ `R` 与 `S` 同时为 1 是非法状态，可能让仿真挂死。清零只用 `R`，`S` 保持悬空或接 0。
- ⚠️ 测试模式下触发器初值可能是 `U`，而 `U` 沿 `Q→D` 自锁——**同步清零压不住 `U`**。仿真内核要把初值置 0。

## 4. 子电路实例（本项目最大的坑）

真实规则（`DefaultClassicAppearance`）：

```
1. 引脚按 facing 分边：facing="east"（输入）→ 盒子西边；facing="west"（输出）→ 东边
2. 每边内部按引脚 y 排序，间距 10px
3. 锚点（实例 loc）落在【东边第一个端口】上  →  东口 = (X, Y + 10j)
4. 西口 = (X - 30, Y + offsetWest - offsetEast + 10i)
```

实测组合：

| 引脚数 | 西端口（输入） | 东端口（输出） |
|---|---|---|
| 1 入 1 出 | `(X-30, Y)` | `(X, Y)` |
| 2 入 1 出 | `(X-30, Y-10)` `(X-30, Y)` | `(X, Y)` |
| 2 入 3 出 | `(X-30, Y)` `(X-30, Y+10)` | `(X,Y)` `(X,Y+10)` `(X,Y+20)` |
| 1 入 3 出 | `(X-30, Y-10)` | `(X,Y)` `(X,Y+10)` `(X,Y+20)` |
| 6 入 2 出 | 挤在 `Y-20 .. Y+30` | `(X,Y)` `(X,Y+10)` |

- **引脚越多越挤**。8 个引脚会被压进 50px 高度，间距只剩 10px——这不是"难布"，是"布不通"。
  设计时主动控制在 **3 入 2 出**以内；能砍的复位/使能脚全砍掉。
- 导线终点必须**精确落在**上述坐标。停在 `loc.x-10` 时，从左侧接近能连上，从右侧接近会差 20px 而不连。
- 子电路内部第一个元件的 y 决定端口顺序，所以**引脚的 y 坐标顺序 = 端口顺序**。
- 历史上"导线穿过子电路端口会 WireRepair 死循环 OOM"的现象，本质与第 3 节的端口短接同源：
  **不要让任何导线穿过端口**。

## 5. 分线器 Splitter（4 位，默认朝向）

```
合并侧（多位那一端）: loc
分线侧（单位那一端）: (loc.x+20, loc.y-20+10i)
```

| 位 | 偏移 |
|---|---|
| `b0` | `(20, -20)` ← **最上** |
| `b1` | `(20, -10)` |
| `b2` | `(20, 0)` |
| `b3` | `(20, +10)` |

- 拆位：4 位总线从左侧进 `loc`，右侧取出 `b0..b3`；喂 `0001` 时 `b0=1` → **`b0` 是最低位**。
- 反向当合并器：把 4 个 1 位送进 `b0..b3`，`loc` 出 4 位总线，位序 `o = b3 b2 b1 b0`，
  **最上面的口是最低位**（别按"从上到下 MSB→LSB"的直觉写）。
- 坑：`b2` 的分线口与合并口**同高**（都在 `loc.y`）。从左侧直接拉线进 `b2` 会穿过合并口 → 短路，必须从**右侧**绕入。
- `fanout=16` 时端口不再按 10px 排列，大位宽不要用单个分线器。

## 6. 十六进制数码管 Hex Digit Display

```
loc      = 数据口，固定 4 位
小数点口 = (loc.x+20, loc.y)，1 位
包围盒   = (-15, -60) 到 (25, 0)     ← 5.0 源码 HexDigit.setOffsetBounds(-15,-60,40,60)
```

- `loc` 落在**底边**上，距左边 15px、距右边 25px；数字是往**上**画的，所以数码管下方不放东西、上方要留 60px。
- 两个数码管水平间距小于 **40** 就会真的叠在一起（不是显示 bug，是元件体重叠）。
- 想显示 1 位信号（如 `cout`）必须补零成 4 位：4 路分线器当合并器，`b0` 接信号，`b1..3` 接 `Ground`，合并口出 4 位总线再进数码管。

## 7. 导线连通语义（决定布线算法）

| 情形 | 是否连通 |
|---|---|
| 线段十字交叉，交点对双方都是**内点** | **不连** |
| 一条线的**端点**落在另一条线上（T 型搭接） | **连**（自动生成节点圆点） |
| 两条**同网**线共线相接 | **会合并成一根**；合并后原端点可能变内点 → 依赖它的搭接失效 |
| 端点落在元件端口上 | 连 |
| 端点悬空 | 不连（`U`） |

因此自动布线器必须：不同网络只允许正交交叉；禁止共线重叠；禁止端点落在别的网络上；
**并且先做共线合并，再判连通**——否则会把"合并后断开"误判成"已连通"。

## 8. 布局与可读性

- **整机一屏**：顶层控制在 **1000×700** 以内（1920 屏 100% 缩放约能看到 1500×800）。引脚 x=200，模块 x=720 间距 150，数码管 x=980 是一个好用的模板。
- **别从 (0,0) 起画**：起点用 `(120,60)`，否则展开子电路时电路贴在画布左上角，左侧引脚标签被面板遮住。
- **子电路内部**控制在 **2000×1600** 以内。超过 3000 宽时打开只有 0.15 倍缩放。压缩手段：行距从 1100 降到 340、模块整体右移 200、去掉横穿全图的长总线。
- 同类模块竖排时行距 **150**（模块高约 60 + 走线空间）；模块内部行距 **340**。
- 每个模块实例加 `label`（FA1…FA8、digit3…），截图讲解时非常有用。

## 9. 缩放与截图

- 画布底部有缩放下拉（自动 / ×½ / ×1 / ×2），快捷键 `Ctrl + 减号` 缩小、`Ctrl + 滚轮` 连续缩放。
- 截图前把缩放设成固定值（×1），否则每次「自动」的结果不一样，拼图对不齐。
