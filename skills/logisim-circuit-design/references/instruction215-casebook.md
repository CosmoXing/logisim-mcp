# 实验5 指令分析和程序设计 2.15 实战复盘

> 交付：`待修/全套210/实验5 指令分析.circ`（17 个电路：实验3 ALU 链 8 个 + 控制器/系统 9 个）。
> 工具：`scripts/v215/gen_lab5.py`、`verify_lab5.py`；`board215.py` 的 `Board.ext()` 新增 `sign=True`。
> 验证：例1/例2/例3 + 例4 三种分支共 **600 行逐拍向量全过**；`ERRCOUNT 0`；六项布线自检 0 错误。

## 1. 电路结构

| 电路 | 与实验4 的差异 |
|---|---|
| Regs | 新增 `Q0~Q3` 输出引脚（直接观测四个寄存器），其余同实验4 |
| PC | 8 位 PC + 行波进位，`Offset` 改为 **IR[3:0] 符号扩展** |
| IR | 同实验4；系统里时钟改接 **T1**（见 K34） |
| ID | 同实验4 的 3-8 译码 |
| CLK 模块 | 同实验4：2 位同步计数器 + 门级 2-4 译码 |
| S-I/B | 立即数改为 **符号扩展**（`Bit Extender type="sign"`） |
| Flag | 增加使能门控：`en = ~(JP|JZ|JC)`（见 K35） |
| CU 控制器 | 同实验4，`Offset` 由系统送 8 位符号扩展值 |
| 系统连接 | 4 片 16×16 ROM + 16 位 4:1 MUX（`Prog[2]` 选择）+ ALU A 通道 MUX + 标志使能逻辑 |

顶层输入：`CLK`、`RST`、`Prog[2]`；输出：`R0~R3`、`PC`、`IR`、`RAMQ`、`FLAGS`、
`RA/RB/BOP/ALUY`、`T0~T3`。`Prog=0/1/2/3` 对应例1/例2/例3/例4。

## 2. 指令格式（2.15 实测）

| 位 | 含义 |
|---|---|
| IR[15:13] | 功能/寻址方式（XYZ，X 为 bit15） |
| IR[12:8] | S-op（S3 S2 S1 S0 Cin） |
| IR[7:6] | C-Reg（目标寄存器） |
| IR[5:4] | SA（A 通道源寄存器） |
| IR[3:2] | SB（B 通道源寄存器） |
| IR[3:0] | 4 位立即数 / 跳转偏移（与 SB 重叠，按补码解释） |

功能码（高 3 位乘 0x2000）：

| fn | 值 | 含义 | R/W | S-B/I | RM | WM | JP | JZ | JC |
|---|---|---|---|---|---|---|---|---|---|
| 000 | 0x0000 | 寄存器运算（RW） | 1 | 0 | 0 | 0 | 0 | 0 | 0 |
| 001 | 0x2000 | 寄存器+立即数（RW） | 1 | 1 | 0 | 0 | 0 | 0 | 0 |
| 010 | 0x4000 | 写主存 WM | 0 | 0 | 0 | 1 | 0 | 0 | 0 |
| 011 | 0x6000 | 读主存 RM | 1 | 0 | 1 | 0 | 0 | 0 | 0 |
| 100 | 0x8000 | 无条件转移 JP | 0 | 1 | 0 | 0 | 1 | 0 | 0 |
| 101 | 0xA000 | ZF=1 转移 JZ | 0 | 1 | 0 | 0 | 0 | 1 | 0 |
| 110 | 0xC000 | CF=1 转移 JC | 0 | 1 | 0 | 0 | 0 | 0 | 1 |
| 111 | 0xE000 | 只读寄存器 RO | 0 | 0 | 0 | 0 | 0 | 0 | 0 |

S-op 表（5 位值 = `S3S2S1S0Cin`；`x` 位取 0 即可）：

| 操作 | S3 S2 S1 S0 Cin | 5 位值 | 高字节 |
|---|---|---|---|
| MOV B | 0 0 0 0 x | 0b00000 = 0x00 | 0x0000 |
| SLL | 0 0 0 1 x | 0b00010 = 0x02 | 0x0200 |
| SHR | 0 0 1 0 x | 0b00100 = 0x04 | 0x0400 |
| SAR | 0 0 1 1 x | 0b00110 = 0x06 | 0x0600 |
| CMP A>B | 0 1 0 0 x | 0b01000 = 0x08 | 0x0800 |
| CMP A=B | 0 1 0 1 x | 0b01010 = 0x0A | 0x0A00 |
| CMP A<B | 0 1 1 0 x | 0b01100 = 0x0C | 0x0C00 |
| ADD | 1 0 0 0 0 | 0b10000 = 0x10 | 0x1000 |
| ADC | 1 0 0 0 1 | 0b10001 = 0x11 | 0x1100 |
| SUB | 1 0 0 1 0 | 0b10010 = 0x12 | 0x1200 |
| SBB | 1 0 0 1 1 | 0b10011 = 0x13 | 0x1300 |
| INC | 1 0 1 0 1 | 0b10101 = 0x15 | 0x1500 |
| NEC | 1 0 1 1 1 | 0b10111 = 0x17 | 0x1700 |
| AND | 1 1 0 0 x | 0b11000 = 0x18 | 0x1800 |
| OR | 1 1 0 1 x | 0b11010 = 0x1A | 0x1A00 |
| NOT | 1 1 1 0 x | 0b11100 = 0x1C | 0x1C00 |
| XOR | 1 1 1 1 x | 0b11110 = 0x1E | 0x1E00 |

S-Regs 例：`2008` → C-Reg=00(R0)、SA=00、SB=10、imm=1000(-8)；
`0040` → C-Reg=01(R1)、SA=00(R0)、SB=00(R0)；
`4038` → WM、SA=11(R3，地址)、SB=10(R2，数据)；
`1084` → ADD、C-Reg=10(R2)、SA=00(R0)、SB=01(R1)。

## 3. 四个程序

| 程序 | 机器码 | 预期 |
|---|---|---|
| 例1 -8×10 | `2008 0040 20C0 0200 0244 0244 0244 1084 4038` | R0=F0、R1=C0、R2=B0、R3=0、RAM[0]=B0 |
| 例2 -4/4 | `200C 0600 0600 0040 20C0 4034` | R0=R1=FF、RAM[0]=FF |
| 例3 斐波那契 | `2001 2041 20C0 1084 4038 15FC 0004 0058 800B` | RAM[0..3]=2,3,5,8；R3 递增 |
| 例4 r0>r1 | `2002 204D 0884 A004 C003 2081 8002 2080 8000` | 2>-3 → R2=1；2=2 → 0；-3<2 → 0 |

逐条说明：

- 例1：`MOV R0,-8` → `MOV R1,R0` → `MOV R3,0` → `SLL R0` 一次 → `SLL R1` 三次
  → `ADD R2,R0,R1` → `STORE R3,R2`。-16 + (-64) = -80 = 0xB0。
- 例2：`MOV R0,-4` → `SAR R0` 两次（FC→FE→FF）→ `MOV R1,R0` → `MOV R3,0`
  → `STORE R3,R1`。`4034` 的 SB=01 表示存 R1；`4038` 是存 R2。
- 例3：循环体从地址 3 开始，`JMP -5` 在地址 8，`PC = 8-5 = 3`，不是 `PC+1-5`。
  `15FC` 的 C-Reg=11、SA=11，INC 作用在 R3 上（见 K36）。
- 例4：`0884` = CMP A>B，C-Reg=R2，把比较结果 0/1 直接写入 R2；
  `A004` = JZ +4（相等跳到 7 清 0）；`C003` = JC +3（小于跳到 7 清 0）；
  `8002` = JMP +2 跳过清 0；地址 8 的 `8000` 原地循环。
  2>-3 时 CF=0、ZF=0，两条条件跳转都不跳，R2 保持 1。

## 4. 关键设计决策

1. **立即数/偏移符号扩展**：例1/2/4 的立即数都是负数，零扩展会变成 +8/+4/+3；
   `Bit Extender` 的 `type` 必须是 `sign`。跳转偏移同样从 IR[3:0] 符号扩展。
2. **移位固定 1 位**：实验3 的 ALU 用 `A[2:0]` 作移位数、B 作数据；实验5 的
   SLL/SHR/SAR 例题都是"移 1 位"，机器码里也没有独立移位数。系统里加一个
   `A 通道 MUX`：`S3S2=00`（MOV/移位）时送 `0x01`，否则送 RA。ALU 本身不改。
3. **比较器用补码**：例4 要 2 > -3；2.15 Comparator 的 `mode` 只有
   `unsigned` / `twosComplement` 两个合法值。实验5 文件里把比较器子电路的
   `mode` 改成 `twosComplement`；实验3 原文件保持 unsigned。
4. **IR 用 T1 取指**：复位后 T0 已经是 1，T0 上升沿要等一整轮才出现；实验4
   的系统实测第一拍取到的是 ROM[1]。改 T1 后复位后第一个 CLK 上升沿就取 ROM[0]。
5. **跳转不更新 Flag**：`en = ~(JP|JZ|JC)`。CMP 的 ZF/CF 在 CMP 的 T3 锁存；
   JZ 执行时 PC 取的是同一个 T3 沿之前的 Flag Q。若 JZ 也更新 Flag，它自己的
   ALU 结果会把 CF/ZF 冲掉，后面的 JC 就失效。
6. **4 片 ROM + Prog**：每片 16 字，`PA4 = PC[3:0]`，D 输出经隧道进 16 位 4:1 MUX。
   未用字填 `0x0000`（MOV R0,R0，无副作用），程序跑出末尾也不会破坏状态。

## 5. 时序与验证

一个指令周期仍为 4 拍，计数器在 CLK 上升沿加 1：

| e%4 | 状态 | 动作 |
|---|---|---|
| 1 | T1 | IR 锁存 ROM[PC]（取指） |
| 2 | T2 | ID 译码 / ALU 组合运算 |
| 3 | T3 | Regs 写回、PC +1 或 +Offset、RAM 写、Flag 锁存 |
| 0 | T0 | 空闲（保留，便于示波） |

复位序列：`(CLK=0,RST=1) → (1,1) → (0,1) → (0,0)`，之后 CLK 1/0 交替。
Regs 不受 RST 清零（新仿真初值 0）；PC/IR/Flag/CLK 计数器由 RST 清零；
RAM 初值 0、不清零。

验证矩阵（`verify_lab5.py`，逐拍在 T1 后比对 IR、T3 后比对
R0~R3/PC/IR/RAMQ/FLAGS）：

| 场景 | 指令数 | 向量行 | 结果 |
|---|---|---|---|
| 例1 -8×10 | 10 | 88 | 全过 |
| 例2 -4/4 | 7 | 64 | 全过 |
| 例3 斐波那契 | 27 | 224 | 全过 |
| 例4 2>-3 | 9 | 80 | 全过 |
| 例4 2=2（临时 ROM 变体） | 8 | 72 | 全过 |
| 例4 -3<2（临时 ROM 变体） | 8 | 72 | 全过 |
| 合计 | — | **600** | **全过** |

例4 的 LT 变体是关键用例：CMP 置 CF=1 → JZ 不跳（若 JZ 清 Flag，CF 会变 0）
→ JC 必须仍看到 CF=1 才跳到清 0 分支。它同时验证了 K35。
